# 🎓 Campus Placement Tracker

A full-stack Campus Placement Management System built using Java, Spring Boot, Spring Security, MySQL, Thymeleaf, Bootstrap, and Hibernate. The application enables administrators to manage placement activities while allowing students to apply for placement drives and track their application status through a secure role-based portal.



## ✨ Features

### Admin
- Secure Admin Login
- Dashboard with statistics
- Manage Students
- Manage Companies
- Manage Placement Drives
- View and manage applications
- Select or Reject applications
- Search and Pagination
- Charts and analytics

### Student
- Secure Student Login
- View Dashboard
- View Profile
- View Available Placement Drives
- Apply for Placement Drives
- Eligibility Check (CGPA)
- Duplicate Application Prevention
- Track Application Status
